# TeamManager

Командный менеджер задач: канбан-доска, диаграмма Ганта, проекты с этапами,
спринты, отчёты, уведомления в Telegram и на почту, живые обновления без
перезагрузки страницы.

## Вход (демо-учётки)

Сайт развёрнут по умолчанию с демо-данными (`SEED_DEMO=true`).

| Логин | Пароль | Роль | Что может |
|---|---|---|---|
| `admin@demo.ru` | `demo123` | **Администратор** | Всё: пользователи, все проекты и задачи |
| `lead@demo.ru` | `demo123` | **Тимлид** | Свои проекты целиком: этапы, участники, задачи |
| `member@demo.ru` | `demo123` | **Менеджер** | Задачи проектов, где он участник |

Регистрации снаружи нет — новых сотрудников создаёт админ на странице
«Пользователи». Для боевого использования смените пароли или удалите
демо-учётки и выключите `SEED_DEMO`.

## Возможности

- **Канбан** — настраиваемые колонки (порядок, цвет, скрытие, «финальная»,
  правила переходов, автоподзадачи), drag&drop карточек, быстрый ввод,
  массовые действия, CSV импорт/экспорт
- **Гант** — шкала от 12 часов до «весь срок», зум, перетаскивание баров
  для сдвига дат, фильтры по проекту/задаче/исполнителю/статусу
- **Проекты** — цель, дедлайн, этапы с ответственными и сроками,
  участники, задачи внутри проекта
- **Спринты** — итерации с датами и своей доской
- **Задачи** — подзадачи, чек-листы, соисполнители и наблюдатели, теги,
  файлы, комментарии, история изменений, учёт времени, шаблоны,
  повторяющиеся задачи
- **Уведомления** — колокольчик в интерфейсе + дублирование в Telegram
  и на почту (см. ниже)
- **Живые обновления** — SSE: изменения коллег видны без перезагрузки
- **Отчёты** — сводка за период, просрочки, выполнено по людям,
  списанное время
- Светлая/тёмная тема, адаптивная вёрстка под мобильные

## Роли и права

| Действие | Админ | Тимлид проекта | Менеджер |
|---|---|---|---|
| Пользователи (создание, роли, удаление) | ✅ | — | — |
| Все проекты и задачи | ✅ | только свои проекты | только где участник |
| Управление проектом, этапами | ✅ | ✅ | — |
| Создавать/править задачи проекта | ✅ | ✅ | ✅ (назначать может только себя) |
| Статусы, комментарии, время | ✅ | ✅ | ✅ |

Все права проверяются на сервере, а не только скрытием кнопок.

## Стек

React 19 + TypeScript + Vite + Tailwind 4 · Express 5 + SQLite
(better-sqlite3) · сессии в httpOnly-cookie · zod-контракты, общие для
клиента и сервера (`shared/contracts`).

## Локальный запуск (разработка)

```bash
npm install
npm run dev        # клиент :5173, API :3001 (прокси настроен)
```

Открыть http://localhost:5173

## Деплой (Docker)

```bash
# .env.production — переменные ниже
docker compose up -d --build
```

Приложение отдаёт и статику, и API на порту `PORT` (в compose проброшен
на 80). База SQLite и загруженные файлы лежат в docker-томах —
переживают обновления.

### Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `SESSION_SECRET` | `dev-secret-change-me` | **Обязательно задать в проде** — `openssl rand -hex 32` |
| `SEED_DEMO` | `true` | Создать демо-данные при первом запуске |
| `PORT` | `3001` | Порт сервера |
| `DATA_DIR` | `./data` | Каталог базы SQLite |
| `UPLOADS_DIR` | `./uploads` | Каталог вложений |
| `MAX_UPLOAD_MB` | `10` | Лимит размера файла |
| `COOKIE_SECURE` | `true` в проде | `false` при работе по http:// (без HTTPS) |
| `TELEGRAM_BOT_TOKEN` | — | Токен бота от @BotFather (см. ниже) |
| `SMTP_HOST/PORT/USER/PASS/FROM` | — | Почтовые уведомления; без настройки выключены |

## Telegram-уведомления

Все уведомления есть внутри приложения (колокольчик в боковом меню).
Чтобы они дополнительно приходили в Telegram:

**1. Создать бота.** Написать [@BotFather](https://t.me/BotFather) →
`/newbot` → придумать имя и username → получить токен вида
`123456:ABC...`. Положить в `.env.production`:

```
TELEGRAM_BOT_TOKEN=9102809674:AAFNW...(ваш токен)
```

и перезапустить контейнер. В логах появится
`[notifications] Telegram-бот активен`.

**2. Привязать сотрудника:**

- В приложении: страница «Команда» → карандаш на своей карточке →
  поле **Telegram** = ваш username **без @** (например `ivan_petrov`)
- В Telegram: написать боту любое сообщение (например «привет»)
- Бот ответит «Готово, Имя! Уведомления TeamManager будут приходить
  сюда» — привязка сделана

**3. Что приходит:** назначение задачи вам, дедлайн сегодня/завтра,
просрочка задачи.

> ⚠️ Токен бота — секрет. Не коммитьте его: файлы `.env*` в `.gitignore`.
> Если токен утёк — перевыпустите у @BotFather командой `/revoke`.

## Почтовые уведомления

Заполнить в `.env.production` SMTP-параметры вашего почтового сервиса:

```
SMTP_HOST=smtp.example.com
SMTP_PORT=465
SMTP_USER=no-reply@example.com
SMTP_PASS=пароль-приложения
SMTP_FROM=TeamManager <no-reply@example.com>
```

Письма с темой «TeamManager: …» приходят на email учётки.

## Структура проекта (модульная)

```
shared/contracts/   типы + zod-схемы + пути API — контракт клиент↔сервер
server/src/
  core/             db, config, errors, uploads, scheduler, seed
  modules/<m>/      index.js / routes.js / service.js / repo.js
client/src/
  app/              роутер, layout, providers
  shared/           ui-kit, api-client, utils
  modules/<m>/      index.ts / api.ts / hooks.ts / components|pages
```

Модули: `auth`, `roles`, `tasks`, `search`, `users`, `checklists`,
`comments`, `files`, `history`, `tags`, `sprints`, `timetracking`,
`templates`, `reports`, `transfer`, `gantt`, `notifications`, `columns`,
`projects`.

Правило: модуль отдаёт наружу только свой `index.*` — правки в одном
модуле не ломают остальные.

Подробный план развития — в `PLAN.md`.
